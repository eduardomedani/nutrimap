# Evollo

Plataforma de gestão, treino e nutrição para profissionais de saúde e performance.

## Estrutura

- `index.html` — painel do profissional
- `app.html` — PWA do aluno (treino + registro de carga)
- `anamnese.html` — questionário pré-consulta
- `admin.html` — administração de convites
- `css/tokens.css` — **design tokens da marca** (fonte única de cor, tipografia, forma e movimento)
- `css/brand.css` — componentes de marca e camada de identidade
- `assets/brand/` — logos (horizontal, vertical, claro, escuro, símbolo)
